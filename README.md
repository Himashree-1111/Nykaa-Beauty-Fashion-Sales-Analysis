# Nykaa-Beauty-Fashion-Sales-Analysis
Sales Analysis Using Excel ,Postgre SQL and PowerBI

Project Overview

This project analyzes a simulated Beauty and Fashion sales dataset containing 1,500 records to identify sales performance, profitability, customer purchasing patterns, and product trends.

The project uses Excel, PostgreSQL, and Power BI to transform raw sales data into meaningful business insights.

Note: This is an independently created practice project using simulated data. It does not contain actual Nykaa company sales data.

Tools & Technologies

- Microsoft Excel – Data cleaning, formulas, KPI calculations and analysis
- PostgreSQL – Data storage, SQL queries and business analysis
- Power BI – Interactive dashboard and data visualization
- DAX – KPI calculations and measures

Key Performance Indicators (KPIs)

- Total Revenue: ₹11,74,556.65
- Total Profit: ₹4,56,047.08
- Profit Margin: 38.83%
- Total Orders: 1,347
- Average Order Value: ₹871.98

KPIs are calculated using successfully delivered orders.

Analysis Performed

- Monthly revenue analysis
- Revenue by product category
- Regional sales performance
- Payment method analysis
- Top 10 products by revenue
- Profitability analysis

Dashboard Features

- Interactive Power BI dashboard
- KPI cards
- Monthly revenue trend
- Product category comparison
- Regional performance visualization
- Payment method distribution
- Interactive slicers for region, sales channel and product category

Project Objective

To demonstrate practical data analytics skills, including data cleaning, SQL querying, KPI development, data visualization, and business insight generation.
